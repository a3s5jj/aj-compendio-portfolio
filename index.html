Four systems that run without a human in the loop. Two are published engineering write-ups, two are runnable code. Every number below comes from a test run I can point at.

THE STORY

Clinics lose patients in the gap between a message arriving and someone answering it. I built a receptionist that replies in seconds and writes the booking straight into the clinic's real Google Calendar, with no staff approval step.

THE CHALLENGE

The replies were never the hard part. Guaranteeing it never double books, never confuses two patients sharing a phone number, and never invents a clinic policy was. Those failures are silent.

THE SOLUTION

The model proposes intent, deterministic branches authorize every write. A generated date table replaced the weekday arithmetic the model kept getting wrong. Event IDs key the bookings, so families sharing a number stay separate. Slots are checked when offered and again before creating. Empty retrieval means unknown, not no, so unsupported questions go to staff.

THE STORY

Document intake breaks the same few ways every time. A retry files the same email twice. An attachment uploads but its row never appears. Each of those looks like a successful run from the outside.

THE CHALLENGE

Making retries safe. The system has to run the same window twice and produce the same result, and refuse to fill gaps in a blurry receipt with plausible guesses.

THE SOLUTION

Two workflows file documents into Drive and write one row each to Sheets. Attachments process serially, folders are found or created, files are reused rather than re-uploaded. Verified against an isolated sandbox: a second run over the same 48 hour window left every count unchanged.

06 / FIELD NOTES

From The Build Log

Things that broke, what the cause turned out to be, and what I changed. Notes from building and running the front desk in production.

Jul 2026 Reliability

The AI agent that hung forever, and the one line that caused it

An agent would stop mid conversation and never return. No error, no timeout, no failed execution to look at. The cause was a node reference inside a Code node running under an agent tool: that combination deadlocks the task runner rather than failing. The fix was to stop reaching backwards for data entirely and pass it forward explicitly instead. A hang is worse than a crash, because nothing tells you it happened.

Aug 2026 Cost

What an AI receptionist actually costs per conversation

I pulled 62 real executions out of the database and measured instead of guessing. It came to roughly $0.0082 per message and about $0.04 per conversation, which puts break even against a part time human somewhere near 151 conversations a month. The surprise was where the waste was: a small number of redundant tool calls accounted for a disproportionate slice of the tokens. Worth measuring before optimizing.

Aug 2026 Retrieval

Teaching a bot Taglish without breaking retrieval

Filipino patients switch between English and Tagalog mid sentence, so the bot has to mirror them. The problem is that a Taglish question generates a Taglish search query, and the knowledge base is in English, so retrieval quietly misses. The fix separates the two: reply in whatever language the patient used, but always search in English. What the user sees and what the system searches do not have to be the same string.
