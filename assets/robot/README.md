# Approved workshop robot

AJ approved the final robot animation before this local portfolio integration on
11 October 2026. The GLB is copied unchanged from the completed
`video_studio/robot-mascot-3d/assets/workshop-robot.glb` deliverable.

- Hero: Greeting, six seconds greeting with two waves, then one second neutral.
- Selected work: Working, six seconds controlling node connections with the
  sideways glowing hand and corrected pointing thumb, then one second neutral.
- Contact introduction: Thinking, eight seconds with the floating head, hand and
  three-dot thought cloud, then one second neutral.

All clips start with activity and have matching loop endpoints. The PNGs are
768×768 transparent renders of the approved GLB, captured from its existing
viewer at 2.5 seconds for Greeting and three seconds for Thinking and Working.
They serve as loading, reduced-motion and unsupported-WebGL fallback artwork.
